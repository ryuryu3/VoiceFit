# VoiceFit
Timer based simple fitness assist — 설문으로 루틴을 만들고 타이머에 맞춰 음성으로 세어주는 헬스 코치 (구 voice-coach).

- 소스: pnpm 모노레포(`apps/voice-coach`, `packages/*`), 빌드 결과: `public/` (Worker `voicefit`)
- 빌드: `bash scripts/build.sh` (테스트 → 빌드 → public 복사)
- 문서: `docs/MVP_REPORT.md`, `docs/PLAN_v0.2.md`
- 운동 이미지: Exercise data by [RepDB](https://repdb.co) (무료 등급, 출처 표기 조건)
- 허브: https://solo-main.alexsryu.workers.dev
