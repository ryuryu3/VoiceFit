## 0. 한 줄 정의

**"폰을 보지 않아도 되는 헬스 루틴 코치"** — 한 번 설정한 루틴을 기억하고, 운동 중에는 타이머에 맞춘 음성(하나·둘…)으로 리드하며, 어떤 화면 크기에서도 필요한 정보만 보여준다.

### 비전앱과의 역할 분리

| 구분 | 비전기반 앱 | 음성기반 퀵앱 (본 플랜) |
|---|---|---|
| 입력 | 카메라(자세 추정) | 터치 최소 |
| 핵심 가치 | 자세 교정·반복 자동 카운트 | 루틴 진행·타이머 음성 리드·기록 |
| 폰 위치 | 거치 필요 | 주머니/손/거치 무관 |
| 공유 | **도메인 모델·운동 엔진·저장소·머신 DB 공유** (§5) | 〃 |

## 1. 사용자 흐름

```
[최초 1회] 설문(30초) → 부위별 강화 방향 제안 → 머신 선택 → 머신별 세트/횟수/중량/타이머 설정 → 저장
[운동일]   앱 열기 → "오늘 루틴 시작" 1탭 (설정 화면 거치지 않음)
          → 지난 중량 자동 적용 → 타이머 음성 리드 + 진행 시각화
          → (머신 점유 시) "나중에" 1탭 또는 드래그 → 완료 → 결과 요약 → 자체 캘린더 기록
```

**설정 기억 원칙**
- 설문 결과·루틴·머신별 세트/횟수/중량/타이머는 기기에 영구 저장, 다음 실행 시 그대로 사용
- 운동 중 중량을 바꾸면 그 값이 **다음 회차 기본값으로 자동 반영** (별도 저장 동작 없음)
- 설문 재실행·루틴 재구성은 **설정 메뉴 안쪽**에만 두고 홈에서는 노출하지 않음
- 앱 삭제·기기 변경 대비: 설정 화면에 **백업 내보내기/가져오기(JSON)** 제공, 클라우드 동기화는 비전앱 DB 공유 시점에 같이 검토

## 2. 기능 명세

### F1. 온보딩 설문 → 부위별 강화 방향 제안 (최초 1회)
- 질문 5~7개, 전부 탭 선택형
  1. 목표: 근비대 / 근력 / 체지방 감량 / 체력·건강 유지 / 재활·자세
  2. 경력: 입문(<3개월) / 초급 / 중급 이상
  3. 주 운동 빈도: 2 / 3 / 4 / 5+회
  4. 1회 운동 가능 시간: 30 / 45 / 60 / 90분
  5. 강화하고 싶은 부위(복수, 바디맵 탭): 가슴·등·어깨·팔·복부·하체·둔근
  6. 불편한 부위(복수) — 해당 부위 머신 제외
  7. 체중 — 칼로리 계산용 (선택, 미입력 시 평균값)
- 출력: 부위별 우선순위 카드 + 주간 분할 제안
- 제안 로직: **규칙 기반 테이블**(목표×경력×빈도 → 분할·볼륨)
- 결과는 Profile로 저장, 이후 재실행하지 않음

### F2. 머신 후보 제시 → 선택 (최초 1회)
- 후보 = **운동 모션 라이브러리**(F9, 1차 30종 → 최종 100종) — **비전앱과 공유하는 공통 DB**
- 설문(목표·경력·강화 부위·불편 부위) 기반으로 **추천 순위**를 매겨 부위별 그룹 카드로 표시, 추천 운동은 미리 체크된 상태
- 각 카드에 **모션 미리보기(썸네일 루프)**, 탭하면 상세: 큰 모션 + 강화 부위 + 간단 운동요령 3줄
- 사용자는 보고 체크 해제/추가만 하면 됨
- 무료: 정지 썸네일 + 운동요령 텍스트 / 유료: 모션 재생

### F3. 머신별 세트·횟수·중량·타이머 설정 (최초 1회, 이후 자동 유지)
- 머신당 기본값 자동 채움, 수정은 스테퍼(+/-) 위주
- 설정 항목
  - 세트 수
  - 반복 수
  - 중량(kg)
  - **회당 시간(초)** — 음성 카운트 간격, **2~6초, 1초 단위 선택**(2/3/4/5/6초), 기본 3초
  - 세트 간 휴식(초) — 기본 60초
- 시간형 운동(플랭크·사이클)은 반복 수 대신 **세트 시간(초)**, 10초 단위 음성 안내
- 세트 예상 시간 = 반복 수 × 회당 시간 → 전체 예상 운동 시간 자동 계산

### F4. 타이머 기반 음성 리드 + 진행 시각화
- 시작: "레그프레스, 1세트, 12회, 60킬로. 3, 2, 1, 시작"
- **회당 시간 간격으로 카운트**: "하나 … 둘 … 셋 …" (예: 3초 간격)
- 마지막 3회는 톤 변경("마지막 셋!"), 세트 종료 시 "세트 끝, 휴식 60초"
- 휴식 10초 전 "준비하세요", 0초에 다음 세트 자동 시작
- 카운트와 실제 동작이 어긋날 때를 위해 화면 아무 곳 탭 = **세트 즉시 완료**
- 화면: **좌우 스와이프로 2개 모드 전환** (하단 점 인디케이터 ●○, 마지막 모드 기억)
  - **① 진행 모드**: 현재 머신 / 세트 진행(●●○) / 현재 반복 / 휴식 타이머 링 / 남은 운동 수 / 예상 종료 시각
  - **② 모션 모드** 🔒유료: 단순화된 머신·자세·**강화 부위 하이라이트**가 움직이는 루프 애니메이션 + 현재 반복·세트를 작게 오버레이
    - 애니메이션 1회 루프 = 설정한 회당 시간(2~6초)에 맞춰 재생 속도 동기화 → 음성 "하나, 둘"과 동작이 일치
    - 휴식 중에는 다음 운동의 모션을 미리 재생
  - 모션 라이브러리 상세는 F9
- 제스처 충돌 방지: 좌우 스와이프 = 모드 전환, 짧은 탭 = 세트 즉시 완료, 남은 운동 리스트의 순서 변경은 **길게 눌러 드래그**로만 동작
- 음성 + 비프음 + 진동(Vibration API) 병행 — 이어폰 없이도 인지 가능

### F5. 순서 변경 (머신 점유 대응)
- 🔴 **"점유중 → 나중에" 원탭**: 현재 머신을 리스트 맨 뒤로, 다음 머신 자동 시작
- 하단 "남은 운동" 리스트 **드래그앤드롭** (길게 눌러 이동)
- 완료한 세트는 유지, 남은 세트만 이동

### F6. 폼팩터 대응 UI (갤럭시 플립·폴드·일반 바)
화면 크기에 따라 레이아웃이 **자동 전환**되는 반응형 3단 구성

| 모드 | 대상 | 표시 내용 |
|---|---|---|
| **미니** | 플립 커버화면(Flex Window), 화면 높이 < 약 500px 또는 정사각형 비율 | 머신명 / 세트 x/y / 큰 카운트 또는 휴식 숫자 / [다음] [나중에] |
| **기본** | 일반 바형, 플립·폴드 접은 메인 | 운동 중 전체 화면 (F4) |
| **와이드** | 폴드 펼침, 태블릿 | 좌: 현재 운동 / 우: 남은 리스트·드래그 상시 노출 |

- CSS 컨테이너 쿼리 + 화면 비율 감지로 구현, 수동 "미니 모드" 토글도 제공
- 플립 커버화면에서 PWA를 띄우려면 갤럭시 **Good Lock → MultiStar** 설정 필요 → 앱 내 1회 안내 가이드 포함
- 폴드 펼침/접힘 시 **진행 상태 끊김 없음**(상태는 화면이 아닌 엔진이 보유)
- 다른 앱을 쓰는 동안: 잠금화면·알림창에 **미디어 컨트롤(Media Session API)**로 현재 머신·세트 표시 + 다음/일시정지 버튼

### F7. 운동 종료 요약
- 총 볼륨(Σ 중량×반복), 총 세트·반복, 운동 시간, 추정 칼로리, 부위별 볼륨 분포, 지난번 대비 증감
- 칼로리: MET × 체중(kg) × 시간(h) — "추정치" 표기

### F8. 자체 캘린더 (외부 연동 없음)
- 앱 내 **월간 캘린더**: 운동한 날 주황 점, 볼륨에 따라 진하기 3단계
- 날짜 탭 → 그날의 **대표 결과 카드**(부위 · 총 볼륨 · 시간 · 칼로리) → 탭하면 머신별 상세
- 상단에 이번 달 운동 일수·연속 운동일(스트릭)

### F9. 운동 모션 라이브러리 (공용 모듈 · 유료 모델 핵심)
- **수록 범위**: 1차 **30종 (대표 머신 15 + 프리웨이트 15)** → 이후 단계적으로 추가해 최종 100종
  - 선정 기준: 국내 헬스장 보유율·사용 빈도가 높은 동작, 부위별 균형(가슴·등·어깨·팔·복부·하체·둔근)
  - 확장 시 같은 스키마로 데이터·모션만 추가 (앱 업데이트 없이 라이브러리 버전만 갱신)

> 부위 커버: 하체·둔근 11 / 등 6 / 가슴 6 / 어깨 4 / 팔 5 / 복부 1 — 복부·맨몸 동작은 2차 확장에서 보강
- **운동 1종당 콘텐츠**
  - 모션: 단순화된 머신 + 인체 실루엣, **강화 부위만 주황 하이라이트**, 1회 반복 루프
  - 강화 부위: 주동근 / 보조근 표시 (바디맵 재사용)
  - 운동요령 3줄: ① 자세 세팅 ② 동작 포인트 ③ 흔한 실수
  - 기본 세트·반복·휴식·MET (기존 Machine 데이터)
- **추천**: 설문 Profile + 운동 기록(부위별 누적 볼륨)으로 점수 산정 → 부족 부위 우선 추천, 불편 부위 제외
- **노출 위치**: 머신 선택(F2), 루틴 편집, 운동 중 모션 모드(F4), 완료 요약의 부위 분포
- **비주얼 스타일 (레퍼런스 이미지 기준)**
  - 사실적인 3D 해부학 인체: 회색 톤 근육 + **강화 부위만 주황(#FF6B1A) 하이라이트**
  - 흰색 단순화 머신·기구, 밝은 회색 라운드 카드 배경, 그림자 최소
  - 비스듬한 3/4 시점으로 머신과 자세가 한눈에 보이게
  - ⚠️ 레퍼런스 이미지는 **스타일 참고용**이며, 상용 일러스트 라이브러리 이미지로 보이므로 직접 사용·트레이싱 금지 — 전부 자체 제작
- **모션 포맷**: 3D 렌더 → **짧은 루프 영상(WebM/MP4)**
  - 레퍼런스처럼 사실적인 근육 표현은 벡터(SVG/Lottie)로는 어렵기 때문에 3D 렌더 방식으로 변경
  - `video.playbackRate`로 **재생 속도를 회당 시간(2~6초)에 맞춰 조절 가능** — GIF의 속도 제어 문제 해결
  - 용량: 운동당 2~3초 루프, 약 100~300KB 목표
  - 썸네일(무료) = 영상의 대표 프레임 정지 이미지(WebP)
  - GIF는 공유·홍보용 내보내기로만 사용
- **제작 파이프라인**
  1. 근육이 부위별로 분리된 3D 해부학 인체 모델 확보 (상용 라이선스 확인 필수)
  2. Blender 파이썬 스크립트(bpy)로 운동별 **관절 각도 키프레임**을 데이터(JSON)로 입력 → 자세 자동 생성
  3. 주동 부위 근육 머티리얼만 주황으로 교체 → 일괄 렌더
  4. 같은 관절 각도 JSON을 비전앱의 자세 비교 기준(`visionRef`)으로 재사용
- **유료 구분 (안)**
  | 무료 | 유료 |
  |---|---|
  | 정지 썸네일 + 운동요령 텍스트 | 모션 재생 · 운동 중 모션 모드 · 기록 기반 개인화 추천 |
- **과금 방식**: **월 구독 + 평생 이용권(1회 구매) 병행**
  - 구독: 신규 운동 추가분 자동 이용, 향후 비전앱 기능 묶음 판매에 유리
  - 평생권: 구독 거부감이 큰 사용자용, 가격은 구독 약 12~18개월치 수준에서 검토
  - PWA 결제: Android는 Google Play 결제(TWA로 스토어 등록 시) 또는 웹 결제(토스페이먼츠·포트원 등) 중 선택 필요 → 출시 전 결정
- **비전앱 공용화**: `exercise-library` 패키지로 분리 — 비전앱은 같은 운동 ID로 **포즈 추정 기준 자세(키포인트 각도 범위)**를 이 패키지에 추가해 자세 비교 기준으로 사용

1. **온보딩 설문** (최초 1회)
2. **강화 방향 제안** (최초 1회)
3. **머신 선택** (최초 1회)

5. **홈** — "오늘 루틴 시작" 대형 버튼, 오늘 루틴 미리보기(머신·중량), 이번 주 미니 캘린더
6. **운동 중** — 좌우 스와이프로 진행/모션 모드 전환 (F4), 미니/기본/와이드 자동 전환 (F6)

9. **설정** — 설문 다시하기, 루틴 편집, 음성 설정, 백업 내보내기/가져오기, 플립 커버화면 가이드

## 5. 비전앱과의 모듈·DB 공유 구조

### 모노레포 구성 (안)
```
health-coach/
├─ packages/
│  ├─ core-domain/      # 타입: Profile, Machine, Routine, Session, SetLog (양 앱 공통)
│  ├─ exercise-library/ # 운동 30→100종: 모션(WebM 루프)·썸네일·강화부위·운동요령·관절각도 JSON·MET·추천 로직 (유료 기능 게이트 포함)
│  ├─ workout-engine/   # 세트/휴식/순서변경 상태머신 (입력 소스 무관)
│  ├─ storage/          # IndexedDB(Dexie) 저장소 + 스키마 마이그레이션 + 백업/복원
│  ├─ metrics/          # 볼륨·칼로리·스트릭 계산
│  └─ ui-kit/           # 주황 테마 토큰, 캘린더, 요약 카드 컴포넌트
├─ apps/
│  ├─ voice-coach/      # 본 앱 (PWA)
│  └─ vision-coach/     # 비전앱
```

### 공유 원칙
- **workout-engine은 "반복 1회 완료" 이벤트만 받음** → 음성앱은 타이머가, 비전앱은 포즈 추정이 이벤트를 발생시키는 구조. 같은 엔진·같은 기록 형식
- SetLog에 `source: 'timer' | 'vision' | 'manual'` 필드로 출처 구분
- 같은 기기·같은 출처(origin)에서 두 앱을 운영하면 IndexedDB 공유 가능, 다른 도메인이면 v0.2에서 Supabase 동기화로 통합
- 스키마 버전 필드 필수 (`schemaVersion`) — 한쪽 앱이 먼저 바뀌어도 깨지지 않게

### 데이터 모델 (공통)
```ts
Profile     { goal, level, freqPerWeek, minutesPerSession, focusParts[], avoidParts[], weightKg?, surveyDoneAt }
Exercise    { id, nameKo, category: 'machine'|'free'|'bodyweight', primaryPart, secondaryParts[], met, defaultSets, defaultReps, defaultRestSec, mode: 'reps'|'time',
              motion: { asset, loopBaseSec, thumb }, tips: [setup, point, mistake], popularityRank, tier: 'free'|'pro',
              visionRef?: { keypointAngleRanges } }   // visionRef는 비전앱이 채움
Routine     { id, name, items: RoutineItem[], updatedAt }
RoutineItem { machineId, sets, reps?, durationSec?, weightKg, secPerRep, restSec, order }
Session     { id, date, routineId, app: 'voice'|'vision', startedAt, endedAt, logs: SetLog[], totalVolume, kcal }
SetLog      { machineId, setNo, reps, weightKg, source, rpe?, skipped }
```
- 기존 Machine은 Exercise로 확장(RoutineItem·SetLog의 machineId는 exerciseId로 사용)
- RoutineItem의 weightKg는 운동 중 변경 시 즉시 갱신 → 다음 회차 기본값 (설정 기억)

### 운동 엔진 상태머신
`READY → COUNTDOWN → WORKING(rep n/N) → SET_DONE → RESTING → (다음 세트 | NEXT_MACHINE) → FINISHED`
- 이벤트: rep_done / tap_complete / defer_machine / reorder / pause / resume / weight_change

### ⚠️ PWA 핵심 리스크 — D1에 기술 검증(spike) 먼저
- Android Chrome에서 **화면이 꺼지거나 다른 앱으로 전환되면 Web Speech TTS와 JS 타이머가 멈추거나 느려질 수 있음**

- 검증 실패 시 플랜 B: Capacitor로 PWA 코드를 감싸 Android 네이티브 백그라운드 서비스 추가 (코드 재사용률 높음)

### 병행 트랙: 모션 라이브러리 제작 (유료 기능)
| 단계 | 기간 | 산출물 |
|---|---|---|
| M1 | 0.5일 | 3D 해부학 인체 모델 라이선스 확보 + 1차 30종 리스트 확정(위 초안) |

- workout-engine·storage가 비전앱에서 import 가능한 패키지 형태
